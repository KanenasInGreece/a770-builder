# briefs/

This folder holds the written tasks ("briefs") handed to a model during profiling or a build: the template every
brief follows, the qualification and reading tasks used to measure a new model, and the cheap-reviewer prompt. The
repository's own in-house regression suite lives under `briefs/suite/`, with its own README. `AGENTS.md` and
`docs/OPERATING.md` say which brief is used for what.
